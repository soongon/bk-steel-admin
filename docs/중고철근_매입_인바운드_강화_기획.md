## 0. 한 줄 결론

홈페이지는 이미 **매입 전용 랜딩 수준**(매입 기준 명시·매입/납품 폼·전화 고정 바·LocalBusiness 구조화 데이터·플레이스 연결)으로 잘 만들어져 있다 [확인]. 문제는 세 가지다. **(1) 측정이 0** — 분석 도구·서치어드바이저·robots/sitemap 이 없고 어드민에도 유입경로 칸이 없다 [확인]. **(2) 블로그가 멈추고 있다** — 3월 15건 → 9월 2건, 10월 0건이고 30건 중 매입 글은 7건뿐이다 [확인 RSS]. **(3) 홈페이지 글과 네이버 글이 83% 동일** 하다 [확인] — 네이버 유사문서 판정으로 둘 중 하나가 묻힐 수 있다. 그래서 순서는 **측정 붙이기(1주) → 블로그 역할 분리·매입 글 비중 역전(즉시) → 폼을 어드민에 연결 + 사진 첨부(2~3주)** 이고, 광고는 측정이 돌아간 뒤다.

## 1. 왜 매입 인바운드인가

| 항목 | 내용 |
|---|---|
| 구조 | 매출(철근 판매)은 영업·입찰·발주 레이더로 밀어내는 **아웃바운드**, 매입(중고철근)은 "남은 철근 처분하고 싶은 사람"이 검색해서 오는 **인바운드**. 인바운드는 단가 협상력이 판매자보다 우리 쪽에 있고, 반복 공급원(철거업체)이 쌓인다. |
| 이미 갖춘 것 [확인] | 매입견적서(PQ) 작성→MMS 전송 2클릭(0075~0077), 판매자 명함 첨부, 카카오워크 신규거래 알림, 시세(`price_history`/`price_curation`), 톤 환산(`item.bars_per_tonne`), 문자 동의 가드. |
| 없는 것 [확인] | 유입경로 기록, 웹 문의 접수(공개 API 라우트 `app/api` 없음), 문의→견적→매입 퍼널 집계, 홈페이지에 노출할 공개 시세. |

## 3. 4단계 전략

### 3.1 측정 (지금 바로, 시스템 작업 2~3일)

1. **유입경로 칸** — `purchase_quote.lead_source`(enum: `homepage`/`blog`/`naver_place`/`referral`/`repeat`/`ad`/`other`) + `lead_note`(검색어·소개자 등 자유 텍스트). 작성 다이얼로그 첫 화면에 **버튼 6개** 로 노출(통화 중 1탭). 미입력 허용하되 목록에 '미기록' 배지. `sales_log` 에도 같은 컬럼을 넣어 전화만 받고 견적을 안 쓴 건도 남긴다.
2. **전화 스크립트 한 줄** — "어디 보고 연락 주셨어요?" 를 받는 즉시 묻는다. 시스템보다 이게 먼저다.
3. **채널별 착신번호 분리** [미결 3] — 홈페이지·블로그에 적는 번호를 다르게(예: 050 가상번호·콜 트래킹 서비스) 두면 묻지 않아도 자동 분류된다. 솔라피·팝빌과 별개 서비스라 월 비용 발생.
4. **웹 분석** — 네이버 서치어드바이저·구글 서치콘솔에 홈페이지 등록(검색 유입 키워드 확인), 네이버 블로그 통계의 '유입 검색어' 주 1회 캡처.
5. **대시보드** — `[book]/dashboard` 에 "매입 문의 퍼널" 카드: 이번 달 문의 n / 견적 n / 매입 n, 유입경로 막대.

### 3.2 유입 확대 (네이버 중심, 2~8주)

판매자는 대부분 **모바일 네이버**에서 검색한다. 키워드는 "매입" 쪽이지 "판매" 쪽이 아니다.

| 키워드 군 | 예시 | 콘텐츠 |
|---|---|---|
| 처분 의도 | 중고철근 매입, 남은 철근 처분, 잔여철근 판매, 철근 팔아요, 철거 철근 매입 | 랜딩·블로그 고정글 |
| 시세 의도 | 중고철근 시세, 철근 고철 단가, 철근 kg당 가격, 철근 톤당 | **주간 시세 글**(가장 강함) |
| 규격 의도 | D10 중고철근, D13 철근 남은거, 8m 철근 처분 | 규격별 사진 가이드 |
| 지역 의도 | {지역} 철근 매입, {지역} 고철 철근 | 플레이스 + 지역 사례 |
| 상황 의도 | 현장 정리 철근, 준공 후 잔재, 공사 중단 철근 | 현장 사례 글 |

실행 항목:

1. **네이버 스마트플레이스 등록** — "신라철강 · 중고철근 매입" 으로, 전화·영업시간·사진(계근 장면·야적장)·리뷰. 지역 검색의 절반은 여기서 끝난다. 무료.
2. **블로그 역할 분리 + 운영 룰** — 지금은 같은 글을 두 곳에 올린다 [확인]. 바꾼다:
   - **네이버 블로그 = 현장 사례 스트림(발견)**. 납품·매입 둘 다 올리되 **매입 글을 2:1 이상**으로 역전(현재 7:23). 매입 글이 없는 주는 지난 매입 건을 "사례 복기"로라도 쓴다.
   - **홈페이지 `/blog` = 매입 기준·시세·가이드(전환)**. 고유 콘텐츠만: 주간 매입 단가, 규격별 기준, 환산표, "팔기 전 체크리스트". 현장 사례는 홈페이지엔 **3~4줄 요약 카드 + 네이버 원문 링크**만 둔다(유사문서 해소).
   - **발행 주기** 주 2회 고정: 월 **"이번 주 중고철근 매입 단가"**(어드민 `price_curation` 자료거래 기준 → 초안 자동 생성 → 사장 수정 발행, 네이버·홈페이지 **다른 문장**으로), 목 **현장 사례**(네이버). 6~7월처럼 0건인 달이 다시 나오지 않게 어드민 홈 '오늘 할 일'에 발행 체크를 넣는다.
   - **제목 룰**: 본제목만 30자 안팎(지역 + 톤수 + 결과). 키워드 꼬리는 **태그란**으로 이동. 예: "울산 10m 정척 철근 120톤 매입 — 당일 계근·현금 정산".
   - B계좌·무자료 관련 문구는 **절대 노출 금지**(절대 룰 2).
3. **고정글 1개** — "중고철근 팔 때 확인할 5가지(규격·길이·녹·묶음·계근)" + 환산표(`bars_per_tonne` 데이터로 "D13 8m 몇 개가 1톤?" 표). 모든 글 끝에 링크.
4. **네이버 지식iN·카페** — "남은 철근 어디 팔아요" 류 질문에 답변(월 4건). 철거·인테리어·소규모 건설 카페에 업체 소개는 카페 규칙 확인 후.
5. **당근마켓 비즈프로필·중고나라 알림** [미결 4] — "철근 팝니다" 글이 올라오는 곳. 알림 키워드 걸어 두고 먼저 연락하는 반(半)인바운드.
6. **네이버 검색광고(파워링크)** — 3.1 측정이 돌아간 뒤, 롱테일("잔여철근 매입" 등 경쟁 낮은 키워드)에 소액. 전환(전화 클릭) 추적 없이 시작하지 않는다 [미결 5: 월 예산].

**어드민 연동(이 repo)** — §4-2. 폼 제출이 어드민 `web_inquiry` 로 들어오고 카카오워크에 즉시 알림 → 사장이 **[견적서 작성]** 누르면 PQ 다이얼로그에 판매자명·연락처·현장·품목이 미리 채워짐 → 저장 후 문자(2클릭, 이미 구축됨).

**응답 룰** — 영업시간 내 **1시간 안에 PQ 문자**. 못 하면 "확인했고 ○시까지 단가 보내드림" 문자 1통(템플릿). 유효기간 짧게(3~5일) 두고 시세 변동 조건 문구 유지.

**후속** — 견적 후 D+2 "계근 일정 잡을까요?", D+7 "단가 변동 있어 다시 안내" (sales_log `follow_up_on` 활용, 홈 대시보드 '오늘 할 일'에 노출). 거절·미응답 사유를 PQ `status` 옆 `lost_reason`(신규)에 기록 → 단가 문제인지 거리 문제인지 보인다.

### 3.4 재거래·소개 (지속)

1. 거래처에 **'철거업체'·'건설사 현장'·'개인' 구분**(partner 에 분류 컬럼 신규 [미결 7]) — 철거업체는 반복 공급원이라 월 1회 시세 문자.
2. 시세 문자는 **문자 동의 가드**(`recipientPhoneConsent`, 거절 기록) 통과한 번호만. 광고성 문자 표기 룰 준수.
3. 소개 리워드 — "소개로 계근 성사 시 톤당 ○원 추가" [미결 8].
4. 매입 완료 후 "계근표+입금 확인" 문자 템플릿 하나. 후기 요청 링크(플레이스 리뷰)를 여기에 붙인다.

## 6. 미결 사항

1. **못 본 것** — 문의 폼 현재 수신처(이메일? 카카오?), 네이버 플레이스 리뷰 수·사진, 블로그 통계(일 방문·유입 검색어), 최근 3개월 매입 문의가 실제 몇 건이고 어디서 왔는지(기억 기준이라도).
2. KPI 목표치 — 1개월 측정 후.
3. 채널별 착신번호(콜 트래킹) 도입 여부·비용.
4. 당근·중고나라 모니터링을 할지(시간 대비).
5. 파워링크 월 예산 상한.
6. 카카오톡 채널 보유 여부.
7. 거래처 분류(철거업체/현장/개인) 컬럼 추가 — 거래처 마스터 변경이라 확인 필요.
8. 소개 리워드 단가.
9. **브랜드** — 매입 인바운드는 사업자(신라철강) 이름으로 쌓이는데, SH철강 법인 설립 후 홈페이지·플레이스를 어느 이름으로 가져갈지. 검색 자산(블로그 누적·리뷰)은 이름을 바꾸면 리셋된다.
10. **주력 검색어** — '잔여철근 매입' vs '중고철근 매입' vs '철근 매입': 네이버 광고 키워드도구에서 월간 조회수 비교 후 1개 고정(제목·설명·블로그명에 통일).
